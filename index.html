Connect to Google Sheets

This syncs your data to Google Sheets so it works across all your devices. Complete these steps once:

  1. Go to sheets.google.com → create a new blank spreadsheet named Band Booster Scheduler.
  2. In the spreadsheet click Extensions → Apps Script. Delete all default code, paste in BandBoosterBackend.gs, set your passphrase on line 10, Save.
  3. In Apps Script click Deploy → New deployment → Web app → Execute as Me → Access Anyone → Deploy → copy the URL.
  4. In your Vercel dashboard → your project → Settings → Environment Variables, add:
    APPS_SCRIPT_URL = the /exec URL
    API_KEY = your passphrase
  5. In Vercel → Deployments → Redeploy.

Click below to test the connection.
